# ui-glassmorphism

A modern glassmorphism landing page and mini design system built with pure HTML, CSS and JavaScript. No build step, no dependencies.

## Features

- Frosted glass panels with layered blur, borders and inner highlights
- Animated gradient blobs and a subtle grid backdrop
- Light and dark themes with persisted preference
- Scroll reveal animations, animated counters and parallax tilt on the hero card
- Interactive component demos: buttons, inputs, switch, progress bars and tabs
- Fully responsive with a mobile navigation drawer
- Respects `prefers-reduced-motion`

## Preview locally

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Structure

- `index.html` - landing page markup and content
- `components.html` - full component library showcase
- `style.css` - design tokens, glass primitives, components, layout and animations
- `script.js` - landing page behavior: theme, reveals, counters, tabs and demos
- `components.js` - component page behavior: theme, modal, toast, tabs and reveals
- `COMMERCIAL.md` - commercial licensing terms
- `NOTICE` - copyright and dual-license summary

## Components included

Buttons (variants and sizes), cards, profile card, stat card, text fields, textarea,
select, switch, checkbox, badges, alerts, progress bars, spinner, skeleton, avatars,
tabs, breadcrumbs, pagination, modal dialog, tooltip, table and toast.
